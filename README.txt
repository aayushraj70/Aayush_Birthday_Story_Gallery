# Aayush Birthday Story Gallery 🎂

## Folder structure

aayush_birthday_gallery/
├── index.html
├── style.css
├── script.js
└── images/
    ├── photo-01.jpg
    ├── photo-02.jpg
    ├── ...
    └── photo-20.jpg

## Add your photos

Put your 20 photos inside the `images` folder using these exact names:

photo-01.jpg
photo-02.jpg
...
photo-20.jpg

The gallery is designed around 9:16 story-style images.

## Run

Open `index.html` in your browser.

For VS Code, you can use Live Server if you already have it installed.

## Included

- Responsive mobile-first gallery
- Full-screen photo viewer
- Swipe navigation on mobile
- Previous/next controls
- Keyboard arrow navigation
- Favourite photos saved in localStorage
- Favourites-only filter
- Random photo button
- Light/dark mode saved locally
- Native Share API with clipboard fallback
- Save photo button
- Smooth scrolling
- Reduced-motion support
- No framework required

Note:
The Save Photo button starts working once the corresponding image file exists.
